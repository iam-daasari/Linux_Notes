**User Management:** 

=> user management is important for accountability and keeping linux environment secure.

=> we can switch user using "su-<username>" from root to user and from user to root is "sudo su-<username>"

**Group Management:**

=> if we give permission to group then permissions will change for all the user instead of changing/giving the permisions to each and every person/user individually that's why this group management is useful in this situation.

=> we can add user into a group using below:

                 +---------------------------------+
    **command:** |usermod -aG <Grouname> <username>|
                 +---------------------------------+
