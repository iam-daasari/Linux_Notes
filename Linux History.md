# Linux History

## Overview

Linux started as a small kernel project and evolved into one of the most widely used technologies in modern computing.

## 1. How Linux Started

* **1991:** Linus Torvalds started developing a new operating system **kernel** as a hobby project while studying in Helsinki, Finland.
* The project became known as the **Linux kernel**.
* The kernel is the **core component** responsible for managing hardware and providing services to applications.

## 2. GNU GPL

* **1992:** Linux was released under the **GNU General Public License (GPL)**.
* GPL allowed developers to:

  * Use the software
  * Study and modify the source code
  * Distribute modified versions
* This helped Linux build a **global open-source developer community**.

## 3. Linux Kernel vs Complete Operating System

The **Linux kernel alone is not a complete operating system**.

A usable Linux system combines the kernel with:

* System libraries
* Utilities
* Applications
* Development tools
* Other system components

Many of these components came from the **GNU Project** and other open-source projects.

**Linux Kernel + GNU/System Components = Linux Distribution**

## 4. Linux Evolution

What started as a hobby project in **1991** evolved into a major foundation of modern computing.

Linux is widely used in:

* **Cloud platforms and servers**
* **Android devices**
* **Embedded systems and IoT**
* **Supercomputers**
* **Medical equipment**
* **Stock market and trading infrastructure**
* **Search engine infrastructure**
* **Weather forecasting**
* **Fitness and specialized devices**

## 5. Open Source Ecosystem

Linux is part of a much larger open-source ecosystem.

Common open-source technologies used around Linux include:

| Technology | Purpose                    |
| ---------- | -------------------------- |
| **GCC**    | Compiler                   |
| **Make**   | Build automation           |
| **glibc**  | Core system library        |
| **Apache** | Web server                 |
| **Nginx**  | Web server / reverse proxy |
| **MySQL**  | Database                   |
| **Python** | Programming language       |
| **Perl**   | Programming language       |
| **Ruby**   | Programming language       |

## Key Takeaways

* Linux started as a **kernel project in 1991**.
* **Linus Torvalds** created the Linux kernel.
* **GPL licensing in 1992** helped establish Linux as a global open-source project.
* The **kernel is only the core**; a complete Linux system requires additional software.
* Linux evolved from a hobby project into a **foundation of modern computing**.
* Linux works as part of a broad **open-source ecosystem**.
